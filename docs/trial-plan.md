# 昭和41年法律第86号 再構築試行手順

本文変更前に作成。対象は改正法の制定時全文と、祝日法・老人福祉法への改正関係。老人福祉法の全文再構築は対象外。

1. 既存リポジトリ・台帳・仕様・検査器のHEADと旧参照を記録し、ローカル試行ブランチを作る。既存main・旧履歴は保持する。公開・マージは今回行わない。
2. 改正文と、その中に引用された条文・表を現行仕様で表せるか確認する。未対応なら本文へ隠さずunsupportedFeaturesを申告し、検査の未完了を成果として記録する。仕様をこの試行に合わせて変更しない。
3. 既取得の御署名原本3画像を再閲覧し、ハッシュを確認する。官報の取得可能性を再調査し、取得できなければREB-05の代替資料として扱う。正誤・字体は確認範囲を明記する。
4. 制定時のRevisionをランダム発行し、本則・制定附則・履歴・必要な字体注記・再構築報告を作る。改正文中の老人福祉法第五条を改正法自身の第五条にしない。
5. 関係は仕様に従い被改正法側へ置く。祝日法の既存関係は保持する。老人福祉法の既存Recordを調査し、既存IDを優先する。新規ならランダムIDを発行し、本文未収録の履歴で関係を記録する。
6. 台帳・L0/L1・L3・rebuild・L4を実行し、JSON結果、原典の閲覧箇所、未対応構造、旧履歴不変を記録する。合格のために構造や未検証状態を省略しない。
7. 結果をまとめる。完了条件は対象資料・本文の表現可否・複数Record間の関係が再現可能な形で検査され、制約と次に必要な仕様対応が明示されること。形式上の完全合格や公開は条件にしない。
