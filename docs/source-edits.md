# 原典照合と表現上の制約

御署名原本 https://www.digital.archives.go.jp/file/686000 のIIIF目録は5画像。全画像を閲覧し、保存画像のハッシュをdownloads.jsonに記録した。

- 1画像：公布文、日付、署名。版本文には収録しない。
- 2画像：法令番号・題名・本則。建国記念の日の日付は印刷の「二月十一日」を見え消しし、手書きで「政令で定める日」。訂正後を収録。手書きの字体は仮置きで、官報照合未了。
- 3画像：附則第一〜三項と、第五項後半・第六項。画像の順だけで転記すると第四項・第五項前半が落ちる。
- 4画像：附則第四〜六項。第五・第六項の表示番号には手書き訂正がある。原番号の判読は未確定で、訂正後の５・６を収録。3画像との重複箇所は一度だけ収録。
- 5画像：右側は厚生大臣署名、左側は次の法律の公布文。版本文に追加しない。

官報号外第78号（1966-06-25）の画像は今回の公開ウェブ検索でも取得できず、REB-05に従い御署名原本を用いた。官報正誤は網羅調査していない。

衆議院制定法律ページ https://www.shugiin.go.jp/internet/itdb_housei.nsf/html/houritsu/05119660625086.htm は全体の照合補助に使用した。旧本文と同様に「附属磯関」「一都」「判り」と表示されているが、4画像では「附属機関」「一部」「削り」と読めるため、画像の字を採った。Web本文の字体を原典の字体の根拠としない。
